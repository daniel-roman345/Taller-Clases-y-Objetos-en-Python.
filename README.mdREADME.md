## Descripción del proyecto

Este proyecto fue desarrollado como evidencia de aprendizaje para la actividad GA1-220501093-04-AA1-EV04 del SENA.

El objetivo es aplicar los conceptos de Programación Orientada a Objetos (POO) en Python mediante la creación de clases, objetos, constructores, atributos y métodos.

En este proyecto se desarrolló el taller "Clases y Objetos", donde se implementó una clase llamada **Libro** para gestionar información básica de una biblioteca.

---

## Contenido

- Clase Libro
- Constructor (`__init__`)
- Atributos
- Métodos
- Creación de objetos
- Pruebas en consola

---

## Diseño de la clase

La clase `Libro` contiene los siguientes atributos:

- titulo
- autor
- paginas
- disponible

También cuenta con los siguientes métodos:

- prestar()
- devolver()
- informacion()
